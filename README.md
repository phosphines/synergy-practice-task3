# Программа обработки числовых массивов и фильтрации данных

Программный модуль на языке Python для автоматизированного анализа числовых списков, динамического выделения срезов и агрегации отфильтрованных данных.

## 📋 Описание логики и алгоритма решения

Алгоритм разработан для решения прикладной задачи анализа массивов в рамках одной сессии обработки данных:
1. **Поиск экстремумов:** С помощью встроенного оптимального метода `.index()` программа за линейное время $O(N)$ находит позиционные индексы минимального и максимального элементов в исходном массиве.
2. **Динамическое индексирование:** Скрипт автоматически сравнивает полученные индексы, корректно определяя левую и правую границы независимо от порядка их расположения в массиве.
3. **Выделение среза:** Формируется изолированный подмассив элементов, находящихся *строго между* экстремумами (граничные элементы исключаются).
4. **Фильтрация и агрегации:** Через синтаксическую конструкцию генераторов списков (*list comprehensions*) из среза отбираются только элементы, удовлетворяющие инварианту отрицательного числа ($x < 0$). На финальном этапе встроенная функция `sum()` вычисляет их итоговую сумму.


## 📊 Пример работы программы
* **Входные данные:** `[12, -3, -5, 2, -1, -8, 4, 1]`
* **Элементы между Max (12) и Min (-8):** `[-3, -5, 2, -1]`
* **Отрицательные элементы в срезе:** `[-3, -5, -1]`
* **Результат работы (сумма):** `-9`
